```
   进入页面 → useQuery Hook → API请求 → 缓存数据 → 展示UI

4. 策略生成流程:
   填写表单 → 提交数据 → API请求 → AI处理 → 返回策略 → 展示结果

5. 交易执行流程:
```

```
【后端数据流】

1. 认证流程:
   POST /auth/login
   → 验证用户名密码
   → 生成JWT Token
   → 返回Token + 用户信息

2. 资产查询流程:
   GET /assets/balance?address=xxx
   → 验证JWT Token
   → 检查Redis缓存
   → 调用Blockchain Service
   → 查询Solana链上数据
   → 缓存结果
   → 返回资产列表

3. 策略生成流程:
   POST /strategy/generate
   → 验证JWT Token
   → 解析用户意图
   → 调用AI Agents Service
   → Intent Agent识别意图
   → Strategy Agent生成策略
   → Risk Agent风险评估
   → 保存到数据库
   → 返回策略方案

4. 策略执行流程:
   POST /strategy/execute
   → 验证JWT Token
   → 查询策略详情
   → 调用Blockchain Service
   → 构建交易指令
   → 返回未签名交易
   → (前端钱包签名)
   → POST /strategy/submit
   → 发送到链上
   → 监听交易状态
   → 更新数据库
   → 返回交易结果

【数据库设计】

users (用户表)
├── id (主键)
├── wallet_address (钱包地址)
├── email
├── risk_level (风险偏好)
└── created_at

strategies (策略表)
├── id (主键)
├── user_id (外键)
├── type (策略类型)
├── status (状态)
├── input_tokens (输入代币)
├── output_tokens (输出代币)
├── estimated_apy (预期收益)
└── created_at

transactions (交易表)
├── id (主键)
├── user_id (外键)
├── strategy_id (外键)
├── signature (交易签名)
├── status (状态)
└── created_at
```

```
   - 每个Agent读写共享状态
   - 状态包含: user_input, intent, strategy, risk, execution

2. 条件路由:
   - 根据Intent结果路由到不同Strategy
   - 根据Risk结果决定是否执行
   - 支持循环和重试

3. 错误处理:
   - 每个Agent捕获异常
   - 记录错误日志
   - 返回友好错误信息

4. 可观测性:
   - 记录每个Agent的输入输出
   - 记录执行时间
   - 支持调试和优化
```

## 5. 关键数据流示例

### 示例1: 用户存款到MarginFi

```
1. 用户输入: "我想把500 USDC存到MarginFi赚利息"

2. 前端 → 后端:
   POST /api/v1/strategy/generate
   {
     "message": "我想把500 USDC存到MarginFi赚利息",
     "wallet_address": "xxx"
   }

3. 后端 → AI服务:
   调用 LangGraph Workflow

4. Intent Agent:
   识别意图 → {type: "lending", protocol: "MarginFi", amount: 500, token: "USDC"}

5. Strategy Agent:
   生成策略 → {action: "deposit", apy: 8.5%, steps: [...]}

6. Risk Agent:
   风险评估 → {risk: "low", approved: true}

7. Execution Agent:
   构建交易 → {instructions: [...], gas: 0.00001}

8. 后端 → 前端:
   返回策略方案和未签名交易

9. 前端:
   展示策略详情 → 用户确认 → 钱包签名 → 发送交易

10. 后端:
    监听交易状态 → 更新数据库 → 推送通知
```
