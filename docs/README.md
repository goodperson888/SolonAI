## 💡 文档使用技巧

### 1. 善用搜索
在VS Code中按 `Cmd+Shift+F` (Mac) 或 `Ctrl+Shift+F` (Windows) 全局搜索关键词

### 2. 收藏常用文档
把常用文档的链接保存到浏览器书签

### 3. 打印架构图
把 `docs/ARCHITECTURE.md` 中的架构图打印出来贴在工位

### 4. 做笔记
在阅读文档时，记录你的疑问和理解

### 5. 及时反馈
发现文档问题或不清楚的地方，及时提出
